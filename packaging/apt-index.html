YT Unsub Detector APT repository

This repository provides the yt-unsub-detector package for Ubuntu 26.10 (stonking). Its packages are architecture-independent.

Obtain the full 40-character signing-key fingerprint through a trusted maintainer channel independent of this website. The commands require Bash, curl, and gpg (gnupg). They download the key into a private temporary directory and ask for the trusted fingerprint before changing system files. If it is unavailable or does not match, stop and contact the maintainer. Do not use trusted=yes or disable signature verification.

(
  set -euo pipefail
  tmpdir=$(mktemp -d)
  trap 'rm -rf "$tmpdir"' EXIT
  curl --fail --silent --show-error --location --proto '=https' --proto-redir '=https' \
    -o "$tmpdir/archive-keyring.gpg" \
    https://patrickbuhagiar24.github.io/youtube/archive-keyring.gpg
  fingerprint=$(gpg --batch --with-colons --show-keys "$tmpdir/archive-keyring.gpg" |
    awk -F: '$1 == "pub" { count++; want = 1; next }
      want && $1 == "fpr" { print $10; want = 0 }
      END { if (count != 1) exit 1 }')
  [[ "$fingerprint" =~ ^[A-F0-9]{40}$ ]] || { echo 'Invalid key fingerprint.' >&2; exit 1; }
  printf 'Downloaded key fingerprint: %s\n' "$fingerprint"
  read -r -p 'Enter the independently verified fingerprint: ' expected
  expected=${expected//[[:space:]]/}
  [[ "${expected^^}" == "$fingerprint" ]] || { echo 'Fingerprint mismatch; nothing installed.' >&2; exit 1; }
  cat > "$tmpdir/yt-unsub-detector.sources" <<'EOF'
Types: deb
URIs: https://patrickbuhagiar24.github.io/youtube/
Suites: stonking
Components: main
Architectures: all
Signed-By: /etc/apt/keyrings/yt-unsub-detector.gpg
EOF
  sudo install -d -m 0755 /etc/apt/keyrings
  sudo install -m 0644 "$tmpdir/archive-keyring.gpg" /etc/apt/keyrings/yt-unsub-detector.gpg
  sudo install -m 0644 "$tmpdir/yt-unsub-detector.sources" /etc/apt/sources.list.d/yt-unsub-detector.sources
  sudo apt update
  sudo apt install yt-unsub-detector
)

The source configuration is generated locally and scopes the verified key to this repository. The temporary directory is removed when the commands finish or fail.

APT registers the extension for Chrome/Chromium automatically. Restart the browser after installation. Optional Google Drive configuration is stored per user under ~/.config/yt-unsub-detector, outside the extension package, using only google-drive.json (file link) and service-account.json (key).
