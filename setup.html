YOUSUB Drive setup

Choose a folder once and YOUSUB will find its configuration files automatically, or select the two files below. Contents are read here in the browser and saved only in this Chrome profile — there is no manual text entry.

Looks for yousub-google-drive.json and service-account.json in the chosen folder.

The old name google-drive.json is no longer accepted. In a file dialog, click the file once and press Open — double-clicking can cancel on Linux.

Select both files to save and sync automatically.
